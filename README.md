# 🚀 Personal Portfolio Website

A modern, clean, and responsive personal portfolio website built to showcase web development projects, technical skills, and professional journey as a Frontend Developer.

## ✨ Key Features

- **Clean & Modern UI/UX**: Minimalist design focused on readability and a seamless user experience.
- **Fully Responsive**: Optimized for all screen sizes (Desktop, Tablet, and Mobile).
- **Project Showcase**: Highlights curated works (including a full-featured Tokopedia Clone built with a component-driven architecture).
- **Direct Professional Links**: Quick access to GitHub, LinkedIn, and direct contact channels.

## 🛠️ Tech Stack

- **HTML5** (Semantic Markup)
- **CSS3** (Flexbox, CSS Grid, Modern Styling)
- **JavaScript (ES6+)** (Interactive UI & DOM Manipulation)
- **Git & GitHub** (Version Control)
